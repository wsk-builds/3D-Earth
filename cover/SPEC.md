## 1. 实现流程（波斯湾封面实际怎么做的）

| 步 | 做什么 | 关键实现 |
|---|---|---|
| ① 光追地球 | moderngl 全屏片元着色器，对单位球做光线求交 | 用仓库根目录的 `globe.py`（撒哈拉视频那颗地球），所有参数保持默认，只设 `t=4.0, cloud_a=0.16, star_a=1.0`。地表贴图是 `textures.earth_rgba()`，由 `tex_b64/` 解码出 NASA Blue Marble 自然色加陆地掩膜；云图是 `cloud_combined_2048.jpg`。**不用 DEM 地形浮雕，也不加 ocean_k 压暗** |
| ② 超采样 | 按 2×（SS=2.0）渲染，比如横版 3840×2160，再用 PIL LANCZOS 缩回目标尺寸 | 球体边缘和星点更干净 |
| ③ 着色器内调色 | 贴图先线性化（^2.2）。海洋用 globe.py 内置的轻微冷色 (.85,.95,1.1)，陆地保持原色。然后依次是漫反射、云和云影、海面高光、大气边缘，再过 ACES 色调映射、gamma 1/2.2，最后加 ±0.5/255 抖动 | 底色和星空也在着色器里生成 |
| ④ 主题特效 | 用 skia 在 2D 画布上叠加：经纬度投影成屏幕坐标，画细线和光点 | 加色混合（kPlus）加模糊，不透明度很低 |
| ⑤ 文字暗角 | 以文字中心为圆心，叠 2 到 3 层黑色径向渐变（scrim），往外渐变到透明 | 只压暗文字周围，没有整圈暗角，也没有底条 |
| ⑥ 排版 | 标题和副标题逐字绘制（可控字距），每个字先画一层模糊投影再画本体；太宽就等比缩小，保证只占一行 | 字体 Noto Serif CJK SC |
| ⑦ 导出 | PNG 无损一份，JPG（quality 92）一份 | 同名同时输出 `cover_landscape.*`、`cover_portrait.*` |

### 2.2 相机与地球

- 球在屏幕上的半径 R = tan(asin(1/dist)) / tan(17.5°) × H/2。

### 2.3 光照、颜色、大气、星空（v2：仓库 globe.py 默认值，横版和竖版通用）
- **太阳方向（近正面光）**：规则取自 `example_wind.py` 的哈德来场景，视点 (5°N, 18°E)，太阳 `sph(3, 46)`。
  - 太阳和视点中心的**大圆夹角固定 28.0°**，**方位角约 94°**（从正北顺时针量，即正东略偏南）。
  - 脚本里的 `sun_latlon(lat, lon)` 按这个夹角和方位角，从每期的视点推出太阳经纬度。不用固定的经纬偏移，是因为高纬度时经度差对应的实际角度会变小，光照就不一致了。
  - 效果：可见的整个球面基本都被照亮，向东略亮；晨昏线在球的背面，看不到。
  - 例子：波斯湾横版视点 (42, 52)，太阳 (34.92, 86.87)；竖版视点 (38, 52)，太阳 (31.61, 85.40)。
- **漫反射**：`smoothstep(-.12,.35,N_bump·L) × clamp(N_bump·L×0.7+0.45, 0, 1)`。光色 (1,.97,.92)×1.25，夜面微光 (.010,.014,.03)。
- **凹凸**：用贴图亮度的梯度扰动陆地法线（强度 1.6），没有 DEM 地形浮雕，也没有积雪层。
- **颜色**：自然卫星色，不调饱和度。海洋是贴图色乘 (.85,.95,1.1)，这是 globe.py 内置的值；**不再乘 ocean_k**。陆地不变。
- **海面高光**：`pow(N·H,600)×1.2 + pow(N·H,40)×.05`，只作用在海洋上。
- **云**：`cloud_a=0.16`，很淡；贴图偏移 `t=4.0`（固定）。云在地面上投下淡淡的影子，强度 0.45×云量。
- **大气边缘（球内）**：`rim=(1-μ)^2.6`，颜色 (.30,.55,1.0)×1.1，强度 0.55，向阳侧更亮。
- **大气光晕（球外）**：`exp(-离地高度/0.022)`，颜色 (.25,.5,1.0)×1.25；晨昏方向有一点暖色 (.6,.35,.2)×0.3。
- **背景**：线性色 (0.004, 0.006, 0.014)，经过 ACES 和 gamma 后实测是 **RGB(12,15,25) ≈ #0C0F19**，深空蓝黑。
- **星空**：方向哈希，`rd×300` 网格里只有 0.4% 的格子点亮，颜色 (.8,.85,1)，`star_a=1.0`。
- **色调映射**：ACES 加 gamma 2.2，`exposure=1.0`。
- **竖版调色**：竖版的地球比横版**略微**鲜亮一点，用户的要求是"略微调得鲜艳一点，亮度稍微调高一点"。
  - 原因：竖版里的球只占画高的 61%，周围大片是深空，在手机信息流里看起来比横版暗、比横版灰。
  - 参数：

    | | 横版 | 竖版 |
    |---|---|---|
    | 曝光 `*_exposure` | 1.00 | **1.08** |
    | 饱和度 `*_saturation` | 1.00 | **1.12** |

  - 做法：在 `grade_globe()` 里处理。
    - **只作用于地球圆盘内**：圆盘半径按 dist 算出来，边缘羽化 1.5 px。文字、暗角、背景、星空和球外光晕都不受影响。
    - 在线性光里先提饱和度，再提曝光。饱和度是围绕亮度加的，色相不变；越亮的地方（云、雪）和越暗的地方加得越少。
    - 曝光以后，0.8 以上用 tanh 软肩压回去，不会硬裁剪。
  - 实测（波斯湾竖版，球面去掉文字带）：
    - 平均亮度 0.389 → 0.402，平均饱和度 0.367 → 0.401。
    - 爆白像素 0%。
    - 海洋 G/B 0.692 → 0.678，略往深蓝走，不偏青。
  - 选定过程：做了 A 1.06/1.08、**B 1.08/1.12（选定）**、C 1.10/1.15 三档。A 几乎看不出区别；C 开始有点"调过"的感觉；B 能看出来，同时仍然自然。对比图见 `previews/portrait_grade_variants.jpg`，三档单图在 `previews/portrait_variants/`。
  - 上限：曝光不超过 1.10、饱和度不超过 1.15。再往上就会显得人工、艳俗，这是用户明确不喜欢的。
  - config 里可以用 `portrait_exposure` / `portrait_saturation` 覆盖（`landscape_*` 同理），一般不要改。
- **暗角**：v2 外观比旧外观亮，但 §2.5 的暗角参数不用改，按现有参数文字仍然清楚（波斯湾和亚马孙两组预览都检查过）。

### 2.4 排版

**“居中稍偏上”的定义**：文字块的墨迹中心（标题顶到副标题底）比画面中线高约 **4%×H**。ty=500/880 就满足这个条件。标题字数变化不影响纵向位置，所以 ty 一般不用动。如果超宽缩小了字号，墨迹中心会下移一点，可以把 ty 往上调，补回字号缩小造成的下移量的一半。【推断，建议】
**地球不跟着文字移动**：地球永远在画面正中，文字的位置只由 ty 决定。

## 3. 视角怎么选（每期判断，方法如下）

**目标**：一眼就能看出“这期讲的是地球上哪里、哪几块地方之间的关系”，而且这块地方不能被标题挡住。

1. **列出重点区域和因果链。** 先写下这期故事必须同框的地方。例如北纬30度要让东亚、青藏高原、中东一起出现，体现“同纬度不同命运”；波斯湾要同时看到阿拉伯半岛、波斯湾和扎格罗斯山；火山带要看到太平洋的大半圈边缘。
2. **定 lon。** 取这些区域经度的中点。v2 的光照是近正面光，整个可见球面基本都亮，所以不用为了避开晨昏线去挪视角。只是球的西缘（画面左边）比东缘稍暗一点，重点区域不要贴着左边缘。
3. **定 lat（最关键）。** 标题压在画面中线偏上，所以重点区域要放在**球心或略低于球心**的位置。做法是让视点 lat 比重点区域的纬度高一些。波斯湾在约 27°N，横版视点 lat 用了 42，海湾因此落在标题和副标题下方、画面中下部。lat 也决定能看到多少纬度带：讲纬度带的选题（北纬30度）要让那条纬线横穿画面，同时看得出弧度。
4. **文字所在的那一带让给次要内容。** 标题横穿球的中上部，那一带最好是次要的陆地、海洋或云，不要压在核心地物上。
5. **竖版单独调。** 竖版画面窄，球相对更小，文字落在球的不同纬度上，所以 lat 往往和横版不一样。波斯湾竖版用了 38，比横版 42 低 4°；北纬30度那期，用户明确要求竖版视角“往南低 2°，不要往北抬”。方向要试出来，不能想当然。
6. **光照自检。** 重点区域要亮度正常，不要落在左边缘那一圈较暗的地方。
7. **出几个变体对比。** 用 `"orients":["l"]` 或单独一个配置文件，在 lat ±2–4°、lon ±5° 范围里渲染 3 到 5 张缩略图放在一起比，挑重点区域最清楚、又不被文字挡住的那张。试的时候可以在 config 里加 `"ss": 0.5`，半分辨率出图更快。多写几个 config（out_dir 分开）批量跑。

### 3.1 取景距离 dist（构图目标，数值是起点）
- **横版**：球比画面高度略大，上下各裁一点，左右露出星空。**起点 dist=3.0**，直径约 1.12H。重点区域比较小的可以拉近到 2.85，比较大的（火山带）可以推远到 3.3。
- **竖版**：**大部分地球露出来，左右两侧各裁掉一小块**，不能看到完整的圆。**起点 dist=5.3**，左右各裁约 45 px；北纬30度用 5.15，左右各裁约 63 px。dist 再大，球就会完整露出来，不符合要求；再小，裁掉的部分又太多。

## 4. 主题特效准则（克制、自然）

用户明确不喜欢“明显、饱和、突兀的发光”，比如翠绿色的发光水汽云团。特效只用来点题，不能抢地球的戏。

| 元素 | 写法（取自往期代码） | 上限 |
|---|---|---|
| 轮廓或线条（海岸、河流、纬线） | 两层：底下是柔光，线宽 10–16 px、模糊 7–10、α ≤ 0.3、加色；上面是细芯，线宽 1.6–4 px、α 0.35–0.55 | 柔光 α 不超过 0.3，细芯不超过 2 px（纬线类最多 4 px） |
| 光点（油田、火山） | 两层：外层光晕半径 7、模糊 6、α 0.4–0.45、加色；内层实心半径 2.2–2.4、α 0.95 | 点不要太密；背面的点（μ<0.25）不画 |
| 区域强调（例如江南稍绿） | 在原有地表色上按亮度保留做色相偏移，权重 ≤ 0.3（北纬30度用了 0.29，掩膜边缘羽化加 fbm 扰动，跳过海洋和湖泊） | 只能让人觉得和周围“略有不同”，不能变成另一种颜色 |
| 箭头和流线（季风） | 柔光 α 0.35、细芯 α 0.55、箭头 α 0.7 | 最多 4 条 |
| 靠近文字处 | 竖版中靠近副标题的线要渐隐（北纬30度在 ty+50 到 ty+190 之间渐隐到 30%） | 文字周围不能有亮线穿过 |
| 背面处理 | 画之前用 `visible(lat,lon)`（视线和法线夹角的余弦）判断，小于 0.02–0.05 的直接不画，0.02–0.32 之间渐隐 | 必须做 |

色板：暖色（油、沙漠、火山）用 #ffb040 / #ffd27a / #ff9a20 / #ffc860；冷色（水汽、季风、河流）用 #7fd4ff / #9fd8ff / #e8f6ff。
**禁止**：大面积饱和色块、高 α 外发光、整球描边、彩虹渐变、文字发光。

## 5. 导出
- 横版和竖版各出 `cover_landscape.png/.jpg`、`cover_portrait.png/.jpg`，放在该期的 `cover/` 目录下。
- PNG 无损；JPG 用 PIL 默认参数，quality=92（波斯湾横版约 415 KB，PNG 约 2.6 MB）。
- 文件已存在时脚本默认拒绝覆盖，需要显式加 `"overwrite": true`。改之前先把旧版另存为 `_v1`、`_v2`。
- 如果视频里出现封面画面（比如北纬30度在 0:17 和结尾），那一帧要和定稿封面**完全一致**，参数照抄 config。

## 8. 自定义特效接口
`effect` 可以填一个 .py 文件的路径，文件里定义 `draw(ctx)`。ctx 里提供这些：
`cv`（skia 画布）、`proj(lat,lon,r=1.004)` 返回 (x,y,深度)、`visible(lat,lon)`、`sph`、`cam`、`sc`、`P`（`coverlib.P` 画笔：颜色、α、stroke/fill、线宽、blur、blend='add'）、`skia`、`W/H`、`orient`、`TY`、`LAT/LON`、`surf`（需要像素级处理时用，比如区域着色，做法：用 `surf.makeImageSnapshot()` 取出像素，在 numpy 里按掩膜混合，再画回画布）。
特效画在 scrim 和文字**之前**，所以文字永远压在特效上面。

## 9. 已知限制
- `cam.py` 在 import 时读取 `EARTH_W` / `EARTH_H`，决定画布尺寸，所以脚本让横版和竖版各跑一个子进程。
- 数据来源：
  - 火山点：原项目的火山表（字段与 Smithsonian GVP 全新世火山表一致，共 1214 个点），这里只保留了经纬度。
- 着色器的海洋判定依赖贴图的 alpha 通道（陆地为 1），所以大湖按陆地着色。
- `tools/fit_view_from_image.py` 只能用在 v2 外观的封面上。往期旧外观的封面用的是另一套着色器，拿它反推会有偏差。
- 云图偏移固定是 t=4.0；换值会改变云的分布，复现旧封面时不要动。
