# 通用插画规范 v2：明艳版 3D 平涂插画

> 适用任何题材（自然、城市、科普示意、产品、室内……），**不绑定某个项目**。
> 基准：用户选定的两帧——**B8-C**（街巷，vivid 1.0）和 **B6-D**（溪流俯视，vivid 1.25）。两帧都在 `style_sheet.png` 里。
> 一句话：**3D 建模的体积和透视 + 三档平涂和墨青描边的插画感 + 鲜但不纯的颜色 + 克制的用色比例和纸纹。**
>
> 标记：【推断】= 有道理但没在本工具包里出过图；【待验证】= 有代码或做法，但没在完整题材里验证过。

## 0. 文件

| 文件 | 作用 |
|---|---|
| `toon.py` | Blender 侧工具：选档、平涂材质、平涂天、灯光、描边、难元素（云、雾、流线、箭头、光束、浪花、海面、清水）、`render_still` 出单帧 |

| `paper.py` | 后期纸纹：颗粒 → 饱和度 → 暖纸调 → 暗角。`python3 paper.py in.png out.png --style vivid --vivid 1.0` |
| `check_frame.py` | 交付前自动测量（§3）。`python3 check_frame.py [--cool] frame.png` |

| `tex/paper.png`、`tex/make_tex.py` | 纸纹贴图及其生成脚本 |
| `ref/B8_C.png`、`ref/B6_D.png` | 用户选定的两张基准帧副本 |

```bash
BL="${BLENDER:-blender}"
$BL -b --python scenes/scene_xxx.py -- --pct 50 [--vivid 1.25]
```

## 1. 风格定义：四种感觉各靠什么做出来

### 1.1 3D 建模感（体积、空间、透视）
- **真 3D 场景 + 真相机**：用几何体、高度场、管线搭模型，24–35 mm 镜头，有真实透视和遮挡。不画 2D 背景板。
- **三档明暗**：每个面落在暗、中、亮三档中的一档（`toon_shade`，CONSTANT 色阶，交界 steps=(.22,.62)）。体积靠档位交界表现，不靠渐变。
- **主光从侧后上方来**：如 `key_light(rot=(55,0,30))`，让主体至少有一面落中档或暗档。正面平光 = 没体积。
- **投影保留**：Eevee 硬阴影落在地面，交代物体的落地关系。
- **空气透视**：远景用雾片（`fog_card`）和更浅的颜色，近中远至少分三层。
- **弧面平滑着色**（shade_smooth）：圆面才会出现干净的档位交界，否则每个面片都被描线。

### 1.2 插画质感（不像渲染图）
- **平涂**：材质全是 Emission，不用 PBR，没有高光渐变、AO、泛光、景深模糊。`toon_setup` 已把这些全部关掉，视图变换用 Standard（Filmic 会发灰）。
- **墨青描边** `#3C4B4B`（不用纯黑）：合成器做法线 Sobel + 对数深度 Sobel，远处淡出。半透明（BLEND）材质不描边——雨、雾、光束、流线不会被描框。
- **表面纹理切硬边色块**：`posterize` 把噪声切成 2–3 个平色块（草地斑块、水纹、木纹）。**不要连续噪声**。
- **纸纹后期**：颗粒 k=.16 + 暖纸调 + 轻暗角。整画面统一在一张纸上。

### 1.3 明艳
- **固有色本身鲜**：vivid 预设把灰青推成湖蓝（色相 186–190°）、灰绿推成嫩芽绿（100–102°），暖色饱和度 ×1.3–1.4。
- **暗部不发灰**：暗档统一偏暖紫 `#E3D6E8`，并按固有色加饱和（shadow_sat .30–.40）。阴影里的草还是绿的、砖还是红的。
- **主光偏暖**：亮档 lit=(1.02,.995,.945)，后期再加 warm .065–.08 和饱和度 ×1.25–1.30。
- **冷暖对比**：湖蓝或嫩绿做大面积，朱红、暖金做点缀焦点。

### 1.4 高级感（明艳而不艳俗）
- **大面积用浅色、中饱和**：地面、墙、桌面、天空占画面一大半，必须是纸色和主色的混合（如 `.6·paper + .4·sand`）。纯色只给小面积。
- **没有纯黑、没有纯白大面**：最暗像素（L<.15）≤ 0.5%；过曝（任一通道 >.995）≤ 4%。
- **焦点色克制**：最鲜的颜色（S>.70 且亮）≤ 8% 画面，只给灯、旗、屋顶、箭头之类的焦点。
- **一个主色调 + 一个对比色 + 1–2 个点缀**，不搞彩虹。
- **留白和秩序**：天空、水面、墙面是“呼吸区”。物件少而精，形体简洁（圆柱、方块、球、高度场），细节集中在焦点附近。

## 2. 两个档位

| 档位 | 用法 | 来源 | 典型题材 |
|---|---|---|---|
| **vivid 1.0（默认）** | `T.use_style('vivid', 1.0)` | B8-C | 有大量白墙、暖土、建筑、室内的画面 |
| **vivid 1.25** | `T.use_style('vivid', 1.25)` | B6-D | 大面积水、植被、冷色主导的画面——冷色要更鲜才不灰 |
| fresh | `T.use_style('fresh')` | 旧的偏青清新版 | 只为兼容旧片；它的测量会落在界线外（偏灰） |

- 0–1.0 在 fresh 和 C 之间插值，1.0–1.25 在 C 和 D 之间插值，最高 1.4（再高就是艳俗区）。
- **必须在建材质之前选档**：色阶参数在材质创建时写死。也可用环境变量 `ILLU_STYLE=vivid ILLU_VIVID=1.25`。
- 纸纹参数随档位走：`paper_kw()`；1.0 = k .16、warm .065、vig .06、sat 1.25；1.25 = warm .08、vig .05、sat 1.30。

## 3. 「明艳而不艳俗」的可测界线（check_frame.py）

成品帧（已加纸纹）逐项测量，全部在界内才能交付：

| 指标 | 含义 | 界线 | B8-C 实测 | B6-D 实测 |
|---|---|---|---|---|
| L | 平均亮度 | .58–.80 | .651 | .714 |
| L10 | 亮度 10% 分位（暗部不压黑） | ≥ .30 | .348 | .648 |
| S | 平均饱和度 | .17–.32（`--cool` 下限 .25） | .198 | .297 |
| Smed | 饱和度中位数（大面积不出纯色） | ≤ .40 | .086 | .306 |
| neon | 高饱和像素 %（S>.70 且 V>.60） | ≤ 8% | 6.64% | 0.12% |
| warm | 暖色像素 %（色相 <65° 或 >320°，S>.15） | 12–45%（`--cool` 下限 0.3%） | 26.94% | 0.35% |
| clip | 过曝像素 % | ≤ 4% | 2.04% | 3.14% |
| dark | L<.15 像素 % | ≤ 0.5% | 0 | 0 |

**`--cool`**：水、海洋、冰雪主导的画面暖色天然很少，这时暖色只需要有一点点（≥0.3%），但冷色本身必须够鲜（S ≥ .25）。

**界线的验证**（同一工具测出）：

| 帧 | 结果 | 说明 |
|---|---|---|
| B8-A、B8-B（旧清新档） | FAIL：S .131/.138 < .17，warm 10.4/10.7% < 12 | 下限挡住“偏青发灰” |
| B6-A、B6-B（`--cool`） | FAIL：S .221/.226 < .25 | 冷画面不够鲜也会被拦 |
| B8-C、B8-D、B6-D | PASS | 用户选定的档位及其邻档在界内 |
| 新场景饱和度再 ×1.4 | 全部 FAIL：S .33–.35 > .32，或 warm 75% > 45 | 上限挡住“艳俗” |
| 饱和度 ×1.8 | FAIL：neon 12–28%、clip 4.2–9% | 荧光色和过曝被拦 |

本次新场景实测（vivid 1.0，50% 分辨率）：

| 帧 | L | L10 | S | Smed | neon | warm | clip | dark | 结果 |
|---|---|---|---|---|---|---|---|---|---|
| example | .770 | .637 | .243 | .244 | 0% | 23.95% | 2.33% | 0 | PASS |
| lighthouse（`--cool`） | .766 | .610 | .263 | .202 | 1.41% | 13.05% | 1.52% | 0 | PASS |
| sandbox | .772 | .556 | .219 | .204 | 0.14% | 40.66% | 1.44% | 0 | PASS |
| template（骨架） | .787 | .654 | .249 | .247 | 1.46% | 20.47% | 1.18% | 0 | PASS |

> 通过检查是必要条件，不是充分条件。指标管住的是“整体颜色有没有越界”，构图、形体、焦点仍然要人眼看。

### 4.2 用色比例
- 大面积主色（地、天、水、墙）合计 ≥ 70%，浅、中饱和。

- 点缀（朱红、暖金、钴蓝箭头）≤ 10%，越鲜的越少。
- 一画面不超过 2 个点缀色。

## 6. 材质与难元素

| 元素 | 状态 | 做法（`toon.py`） |
|---|---|---|
| 实体物件 | 已用 | `toon(name, base, levels=…)`；base 可以是颜色或 `lambda m: socket`（色带、噪声色块）。大面积 levels 用 (.55,.76,.84–.92) |
| 发光体（灯、灯笼、屏幕） | 已用 | `flat(name, col, strength=2.1)`：不受光的平涂 |
| 平涂天 | 已用 | `sky_world(sc, horizon, top, z_range)`：两色渐变；冷题材天顶给 `#A9D5DA` |
| 海面 | 已验证（灯塔） | `sea_mat()`：世界坐标噪声切 深/中/浅/浪花 四档，沿浪向拉长 stretch=(1,3.5) |
| 河、湖、浅水 | 已用 | 平面 + `toon(teal, gloss=.25)`，或 `clear_water()`（透明水体 + 涟漪）【待验证：清水只在 B6 原镜头用过】 |
| 浪花、礁石白边 | 已验证 | `foam_disc(name, loc, radius, wobble)`：不规则白圈贴水面 |
| 雾 | 已验证 | `fog_card(name, loc, (宽, 高), alpha_max)`：竖向渐隐卡片。**宽度要远大于画面（500）**，否则侧边露硬边 |
| 云 | 已验证 | `puffs(name, [(x,y,z,r)…])`：几个球拼成的团，levels (.84,.93,1.0)；亮色 ≤ .93，否则过曝 |
| 烟、蒸汽 | 已验证（马克杯） | 细 `flowline` 弯曲上升；体积烟：`puffs(alpha<1)` 渐小向上【待验证】 |
| 雨 | 已验证（沙盘） | 短竖 `flowline`，teal_l，alpha .6–.8；大场景雨用深度 alpha 的竖片【待验证】 |
| 雪 | 【推断】 | 小白 ico 球或面片，flat 暖白、无描边（alpha .95 走 BLEND）；地面积雪用 `band_by_normal_z` 顶面切白 |
| 火 | 【推断】 | 2–3 层套叠的锥形 flat：外 red、中 gold、内 `#FFF3C8`，alpha .9；不要体积火、不要泛光 |
| 气流、风、水流 | 已验证 | `flowline(pts, color, alpha=.95)` + `arrow_head`。**必须 alpha<1（BLEND）**，否则整条被描成墨线 |
| 光束 | 已验证（灯塔、台灯） | `beam(apex, direction, length, r0, r1, bands=3)`：分档半透明锥，暖金 |
| 植被 | 已验证 | 树干 tube/圆柱 + `puffs` 树冠，`band_by_z` 下 green 上 green_l；草地用噪声色块，不种单根草 |
| 岩石、悬崖 | 已验证 | ico 球平滑 + `band_by_normal_z`（侧面石色，顶面苔绿）；崖面用 stone 和 sand 混的赭色分层 |
| 地形 | 已验证（沙盘） | `grid_mesh` 高度场；等高台阶用 smoothstep 斜坡（frac .78–1），色带按高度切 sand→草→绿→金→白 |
| 建筑 | 已验证 | 方块 + 板材屋顶；山墙用白色网格单独做，屋顶用两块斜板；门窗是薄盒子 |
| 人物 | 【推断】 | 胶囊身体 + 球头，不做五官或只点两点 black；衣服用点缀色作焦点；比例 4–5 头身；背对或侧对镜头最安全 |
| 文字、标注 | 【推断】 | 不在 3D 里做文字；后期在纸纹之上叠字（规则同 §7.3） |

## 7. 相机、构图、字幕

### 7.1 相机
- 焦距 24–35 mm。俯视 3/4（沙盘、地图）、平视略仰（灯塔、建筑）、一点透视（街巷）都可以。
- `look_at(cam, target, up=(0,0,1))`——**一定传 up=Z**，地平线才水平。
- 渲染：50% 预览（960×540）检查；终稿 100%。只渲单帧。

### 7.2 构图
- 主体放三分线附近，占画面 25–45%。
- 一个焦点：最鲜的点缀色、最强的明暗对比、最多的细节都放在同一处。
- 前、中、远三层：前景道具或岸线 → 中景主体 → 远景山、雾、云。
- 天空或大面浅色至少留 25% 呼吸区；地平线不切画面正中。
- 斜线引导视线：岸线、河流、箭头、光束都指向焦点。
- 道具（笔、尺、杯子）可以被画框裁掉一部分，主体不能被裁。

### 7.3 字幕
| 项 | 值 |
|---|---|
| 字体 | 思源黑体 / Noto Sans CJK SC Medium，1080p 下 50 px，白色 |
| 位置 | 水平居中，文字中心 y = H − 150 |
| **描边** | **3 px 深色**（INK `#3C4B4B` 或 `#2B393B`），模糊 .8，α .88 |
| 投影 | 偏移 (2,3)，模糊 7，α .80 |
| 长度 | 单行，约 18 字以内 |
| 淡入淡出 | 0.18 s |

字幕叠在白墙、白云、浪花上也必须看得清——这就是 3 px 描边的作用。字幕在纸纹之后叠加，不吃纸纹。

## 8. 踩过的坑

| # | 现象 | 原因 | 做法 |
|---|---|---|---|
| 1 | 地面/桌面/墙一片死白，clip 高 | 大面积亮档 1.0 | 大面积 levels 亮档压到 .84–.92 |
| 2 | 整画面俗、warm、S 超标（示例初版 clip 51%、warm 66%） | 纯沙色、纯木色、纯金色铺满大面 | 大面积颜色和 paper 混（如 `.6·paper+.4·sand`），纯色只给小面积 |
| 3 | 整画面发绿发灰，warm 只有 1.7% | 只用冷色和绿 | 地面混入暖土色块，加暖色焦点 |
| 4 | 噪声纹理几乎不变（大片一个色或二值） | 放大的基本体 Object/Generated 坐标只有 −1..1 | 用 `T.wpos(m)` 世界坐标 |
| 5 | 雾片侧边露出矩形硬边 | 卡片不够宽 | 雾片宽 500 |
| 6 | 地平线是歪的 | `look_at` 默认 up 提示 | `up=(0,0,1)` |
| 7 | 台阶地形出现网格状细密排线 | 硬 `floor()` 台阶 + 陡坡挤在一起 | smoothstep 斜坡；山坡放缓；网格加密（沙盘 520×338） |
| 8 | 细箭头、流线变成一根黑线 | 不透明物体被描边 | alpha .95（BLEND） |
| 9 | 坡屋顶端头露出红色截面 | 3 顶点圆柱做屋顶 | 山墙白网格 + 两块斜板 |
| 10 | 主体一面全亮，没体积 | 光从相机方向来 | 主光放侧后上方，如 (55,0,30) |
| 11 | 冷色海景 S 不够（`--cool` 不过） | 天空灰白 | 天顶加湖蓝 `#A9D5DA`，海面用 1.25 档或 sea_mat 的亮档 |
| 12 | 云、白纸过曝 | 白色 × 亮档 1.0 | 云色 ≤ .93 |
| 13 | 河在俯视里看不见 | 河道太窄、刻得太浅、两岸陡 | 宽 V 形河谷 + 河床压到水面以下 + 红箭头沿河 |
| 14 | 改了预设颜色没变 | 材质建好后才 `use_style` | 脚本第一步选档 |
| 15 | Filmic 下画面发灰 | 视图变换 | `toon_setup` 用 Standard |
| 16 | 弧面上布满描线 | 没平滑着色 | `shade_smooth()`；物件少的画面描边阈值用 nthr (.8,1.4) |

## 9. 新题材工作流

1. **定题材和档位**：从 §5 选 `theme`；暖/中性画面 vivid 1.0，水/植被/冰雪主导用 1.25 并加 `--cool`。
2. **复制骨架**：`cp new_scene_template.py scenes/scene_xxx.py`，改输出名。
3. **先定相机**再搭模型：主体、地平线、呼吸区位置先定。
4. **大面 → 主体 → 焦点 → 难元素 → 远景层**，每加一层渲一次 50% 单帧（几秒）。
5. **看图 + 看数**：`render_still` 自动打印 check_frame；FAIL 时照 §8 对症改（warm 高→大面混 paper；S 低→加冷色饱和或换 1.25；clip 高→压亮档）。
6. **交付前过 §10 清单**，终稿 100% 渲染。

骨架（`new_scene_template.py`，可直接运行并通过检查）：

```python
import sys, os
HERE = os.path.dirname(os.path.abspath(__file__))
if os.path.basename(HERE) == 'scenes': HERE = os.path.dirname(HERE)
sys.path.insert(0, HERE)
import bpy
from bl_common import reset, setup_render, camera, look_at, assign
import toon as T, style

a = sys.argv[sys.argv.index('--')+1:] if '--' in sys.argv else []
opt = lambda k, d: type(d)(a[a.index(k)+1]) if k in a else d
COOL = '--cool' in a

# ① 选档（必须在建材质之前）+ 题材色
T.use_style('vivid', opt('--vivid', 1.0)); PAL = T.PAL
th = style.theme('landscape'); MAIN1, MAIN2, MAIN3 = th['main']; ACC1, ACC2 = th['accent']

# ② 场景、平涂天、光
sc = reset(); setup_render(sc); T.toon_setup(sc)
T.sky_world(sc)
T.key_light('Sun', (55, 0, 30), energy=3.0)
T.fill_light('Fill', (-8, -6, 7), energy=200)

# ③ 大面：亮档 ≤ .84–.92；浅、中饱和；世界坐标噪声切硬边色块
EARTH = tuple(.6*p + .4*q for p, q in zip(PAL['paper'], PAL['sand']))
ground = lambda m: T.posterize(m, T.noise(m, .09, 1., .4, vec=T.wpos(m)).outputs['Fac'],
                               [(0., PAL['green']), (.40, PAL['green_l']), (.53, EARTH)])
bpy.ops.mesh.primitive_plane_add(size=200); assign(bpy.context.object, T.toon('ground', ground, levels=(.55, .76, .84)))

# ④ 主体 + 一个暖色焦点
bpy.ops.mesh.primitive_cube_add(size=1.4, location=(0, 0, .7))
assign(bpy.context.object, T.toon('body', PAL['wall'], levels=(.62, .86, 1.0)))
# ……屋顶 ACC2、树 band_by_z(green→green_l)……

# ⑤ 难元素：云 / 雾片 / 流线
T.puffs('cloud', [(-1, 12, 4.6, 1.0), (.2, 12, 5.0, 1.3), (1.6, 12, 4.6, .9)])
T.fog_card('fog', (0, 14, .8), (500, 3.), alpha_max=.5)

# ⑥ 相机：24–35 mm，up=Z
cam = camera(sc, lens=30.); cam.location = (-6, -7, 3.2); look_at(cam, (.6, 1.0, 1.4), up=(0, 0, 1))

# ⑦ 描边 → 单帧 → 纸纹 → 自检
T.comp_outline(sc, nthr=(.8, 1.4), zthr=(.06, .14))
T.render_still(sc, os.path.join(HERE, 'out', 'xxx.png'), pct=opt('--pct', 50), cool=COOL)
```
